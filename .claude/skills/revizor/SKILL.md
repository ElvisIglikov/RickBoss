# Ревизор

Каждый агент раздувает свой кусок, стыки рвутся. Ревизия ловит это до следующей фичи. Код не правит: находки и
план чистки по [workflow](../workflow/SKILL.md).

## Карты, не код

Оркестратор читает паспорт, HANDOFF.md, `docs/status.md`, `git log -60`, строки по папкам, 30 больших файлов,
открытые задачи (`python3 <папка Рика>/tools/tasks.py list --project <Проект> --open`) и режет на зоны. Код
читают ревизоры — со снимка `git worktree add <путь> <коммит>`, живую работу не останавливают. Снимок — вне папки
проекта: иначе его подхватят поиск и тесты.

## Зоны

- 5–10 зон по ответственности: список файлов с числами, названные стыки.
- Сверх кода: что заметят пользователь и владелец после выпуска; тесты, сборка, секреты; польза самих тестов
  (оставить / переписать / объединить / удалить); тексты для людей.
- Три сквозных сценария поперёк зон: ищи потери, дубли, разрыв документа и кода.
- Зона — один агент, только чтение: без внешних запросов, личных данных, полных сборок. Покрытие: файл «прочитан /
  проверен прогоном / не проверен».

## Отчёт зоны

Вердикт 2–4 фразы, здоровье 1–5, находки, «оставить как есть» с причиной, покрытие, вопросы с «(рекомендую)».
Находка: дефект / гипотеза / улучшение, `файл:строка@коммит`, кого ударит, доказательство, минимальная правка, как
принять, часы. В промпт: «не выдумывай ради объёма, не хвали, известное за новое не выдавай». Числа — командами.
Отчёт — сразу в `docs/revizor/<дата>/<зона>.json`.

## Синтез

- Одна беда из разных зон — одна задача, один владелец файла; разное с похожим заголовком не склеивать.
- Агент [checker](../../agents/checker.md) пытается опровергнуть важные находки на текущем HEAD; без доказательства —
  гипотеза.
- Часы ревизоров ×1,5. Здоровье 3–4 — не норма, цель — 5.
- После синтеза снимок убрать: `git worktree remove <путь>`.

## После

- Находки — задачи пачкой: `python3 <папка Рика>/tools/tasks.py add-json -`.
- Чистка по workflow — до следующей фичи, без «оставить как есть».
- Хозяину — HTML по [html-files](../html-files/SKILL.md): до выпуска, позже, оставить как есть.
- **Без уроков ревизия не закрыта:** `docs/revizor-lessons.md` проекта — лучший вопрос, удачная нарезка, типовая
  болезнь, ошибки ревизоров, цена. С датой; устаревшее правь.
