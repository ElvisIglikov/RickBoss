# Рик — главный чат над всеми твоими проектами

Поставил Claude Code — и Рик работает: никаких серверов, аккаунтов и окон. Рика можно использовать отдельно, прямо из коробки: открыл папку — и херачишь.

Ты говоришь с ним обычной речью. Он сам раздаёт работу чатам проектов в терминале, следит, чтобы ничего не
потерялось, и докладывает коротко. Самое главное в Рике — манера ответов: ты читаешь урывками, между делами, а он
отвечает так, чтобы с одного взгляда было ясно, всё ли хорошо и что нужно от тебя.

## Установка — три шага

Нужны macOS, [Claude Code](https://claude.com/claude-code), python3 3.9+ и tmux (`brew install tmux`).

```bash
git clone <адрес этого репозитория> rick && cd rick
./install.sh
claude
```

Установка спросит, как тебя звать, в каком режиме работать чатам проектов и будить ли Рика их ответами, создаст
`config.json` и память из шаблонов. Без sudo, никуда не входит и никому ничего
не шлёт.

Скажи: **привет, Рик**.

## Как он отвечает

```
**❗ Нужно от тебя: ключ оплаты, две минуты**
Сейчас: сайт собран, ждёт только ключ.
**1. Каталог** — всё с фото, кроме двух товаров, досниму к 18:00.
**2. Рассылка** — черновик готов, ждёт твоего «да».
Сайт · жду ❓
```

Нужно действие от тебя — оно первым. Вердикт — одной строкой. Дальше — что сделано и что идёт, темы с номерами:
отвечаешь номером. Без вступлений, извинений и пересказа шагов. Характер — с огоньком: сарказм, рубленые фразы, но
дело делает точно. Форма — стиль ответа `.claude/output-styles/rick.md` (включён в `.claude/settings.json`),
примеры — скилл `.claude/skills/manera`.

## Что внутри

- `CLAUDE.md` — кто такой Рик: характер, манера, правила безопасности.
- `.claude/skills/` — скиллы: `manera` (форма ответа), `orchestrator` (чаты проектов), `workflow` (большая работа:
  план → критик → волны → проверка), `revizor` (ревизия всего проекта), `html-files` (отчёты одним экраном).
  Работают без установки — Claude Code берёт их из папки проекта.
- `.claude/agents/` — помощники workflow: `critic` ищет дыры в плане до работы, `checker` проверяет готовое по фактам.
- `tools/term.py` — чаты проектов в терминале: открыть, дать поручение, прочитать экран, список с контекстом и
  простоем. Подробно — `docs/terminals.md`.
- `tools/rick_bus.py` — почта: чаты проектов отвечают Рику одной строкой, ответ приходит ему в начале хода.
- `tools/tasks.py` — задачи с номерами #N: каждое твоё дело Рик записывает сразу, ничего не теряется.
- `tools/digest.py` — «что у нас» по всем проектам одним вызовом, без обхода чатов; `--html` — сводка файлом.
- `tools/statusline.py` — строка внизу терминала: контекст, кэш, чаты, почта, задачи. Ни одного токена.
- `tools/mem_hook.py`, `tools/mem_guard.py` и `.claude/settings.json` — хуки памяти: в начале чата Рик видит, что
  сейчас; каждый ход — почту чатов и предупреждения.
- `memory/` и `journal/` — память: что сейчас, досье проектов, люди, журнал по дням. Живёт только у тебя: в git —
  только шаблоны `memory/*.example.md`.

## Чаты проектов — терминалы, а не окна

Каждый проект — чат Claude Code в tmux (`rick-<Проект>`): Рик открывает, гасит и сменяет его сам через
`tools/term.py`, пишет туда поручения и проверяет, что они дошли. Доверие к папкам твоих проектов (`projects_root`)
он подтверждает сам, кроме папок, где есть своя папка `.claude` или `.mcp.json` (их хуки, MCP и скиллы запустятся) —
там спросит тебя; ответить ему чат может без вопроса.

Режим чатов — `permission_mode` в `config.json`, установка спросит:

- **спрашивают разрешения** (`default`, по умолчанию) — как обычный Claude Code. Чат иногда ждёт твоего «да» на
  команду или правку; Рик скажет, что нажать, и даст команду `tmux attach -t '=<сессия>'` (выйти — `Ctrl+b d`).
- **без вопросов** (`bypassPermissions` + `term_confirm_dialogs`) — чаты делают всё сами, в терминалы ты не
  ходишь: быстрее, но на твой риск.
- **auto** (`auto` + `term_confirm_dialogs`) — Claude сам проверяет каждое действие и блокирует рискованное; в
  терминалы ты почти не ходишь. Рекомендую, если твой Claude Code его знает: установка предложит его, только когда
  `claude --help` его показывает (зависит от версии и тарифа).

Раздал поручения — Рик держит фоном `term.py watch`: чат встал на вопрос — Рик узнаёт за минуту, а не с твоим
следующим словом.

Без `wake_on_mail` Рик работает, пока ты пишешь: ответы чатов приходят со следующим твоим словом. Чтобы он вёл чаты,
пока ты спишь, — `"wake_on_mail": true` (каждое пробуждение — платный ход).

## По желанию

Всё внешнее выключено, пока ты не положишь ключ.

- **Озвучка ответов.** Рик озвучивает суть ответа системным голосом Мака — спросит разрешения в новом чате. Красивый
  голос — ElevenLabs: ключ в `voice/.env` и `"engine": "elevenlabs"` в `config.json`.
- **Разговор голосом.** Говоришь с Риком голосом через страницу в браузере (OpenAI Realtime), запуск — `live/start.sh`.
  Ключ и настройка — `docs/voice-live.md`.
- **Telegram-бот.** Рик присылает тебе файлы и отчёты в чат с твоим ботом (`tools/bot_send.py`, ключи — `.env` по
  образцу `.env.example`). Подробно — `docs/telegram.md`.
- **Юзербот Telegram** (`./install.sh --telegram`) — Рик читает и пишет от твоего аккаунта. ⚠️ Telegram банит
  аккаунты за похожее на рассылку. Рик не отправляет ни одного сообщения без твоего «да» на черновик, но риск бана —
  твой.

## Чего Рик не умеет

Рик честно говорит, чего у него нет, и не обещает лишнего.

- **Своего будильника и календаря нет.** Claude живёт, пока открыт чат: закрыл — таймеры умерли. На «напомни…» Рик
  ставит напоминание в приложение «Напоминания» Мака (`tools/remind.py`) — напомнит Мак, даже если Claude закрыт.
- **Задачи — список, а не трекер.** `tools/tasks.py` помнит номер, слова и статус каждого дела; сроков, людей и
  повторов в нём нет.
- **Сам не проснётся.** Без `wake_on_mail` ответы чатов Рик увидит с твоим следующим словом.
- **Telegram — только после подключения**: бот — ключи в `.env`, юзербот — `./install.sh --telegram` и вход, минут
  пять. До этого Рик покажет черновик, но не отправит.
- **Браузер** — только если в Claude Code подключены инструменты браузера.
- **Разговор голосом** — только со страницей `live/start.sh` и ключом OpenAI; без неё Рик лишь озвучивает ответы
  голосом Мака.

## Команды

Рик зовёт их сам; тебе — чтобы знать, что внутри.

- `python3 tools/rick_config.py status` — что работает прямо сейчас: Telegram, озвучка ответов, разговор голосом,
  Напоминания, будят ли Рика ответы чатов. Ключи не выводит — только «есть / нет». Рик смотрит сюда, прежде чем
  сказать «не подключено».
- `python3 tools/remind.py "позвонить бухгалтеру" --at "ГГГГ-ММ-ДД ЧЧ:ММ"` — напоминание в «Напоминания» Мака. Так
  Рик ставит их сам на «напомни…»; в первый раз Мак спросит доступ — нажми «Разрешить».
- `python3 tools/tasks.py add|add-json|list|show|start|done|cancel` — задачи #N (`memory/tasks.jsonl`); лишнюю Рик не
  удаляет, а отменяет с причиной.
- `python3 tools/digest.py [--html --open]` — что у нас по всем проектам: идут, ждут тебя, тихо.
- `python3 tools/notify.py "текст" [--sound Glass]` — баннер и звук Мака. Ход дольше минуты кончается звуком сам, а
  если ответ ждёт тебя — ещё и баннером; выключается в `config.json` → `notify`.
- `python3 tools/term.py up|send|read|list|watch|stop|projects` — чаты проектов, подробно — `docs/terminals.md`.
- Эти команды, запись задач для чатов проектов (папка `state/`) и создание папки проекта уже разрешены в
  `.claude/settings.json` — Рик не дёргает тебя подтверждениями на каждом шаге.

С телефона: `claude --remote-control Рик` в папке Рика — тот же чат открывается в приложении Claude и на claude.ai.
Работает не на всех тарифах и версиях Claude Code: нет флага в `claude --help` — нет и Remote Control.

## Приватность

- Память, журнал, настройки и ключи лежат только у тебя и не попадают в git (`.gitignore`).
- Разговор с Риком идёт в Anthropic, как любой разговор в Claude Code.
- Озвучка голосом Мака работает без сети. С ключом ElevenLabs туда уходят тексты, которые Рик озвучивает.
- Разговор голосом отправляет в OpenAI твою речь, ответы Рика и `memory/NOW.md` (что сейчас идёт).
- Telegram получает только то, что ты разрешил отправить.

## Только macOS

Рик опирается на tmux, `say` и `afplay`. На Linux и Windows не проверялся.

## Настройки

`config.json` (образец — `config.example.json`):

- `owner` — как Рик тебя зовёт.
- `projects_root` — где лежат папки проектов, по умолчанию `~/Projects`.
- `model`, `effort`, `permission_mode` — модель, эффорт и режим чатов проектов (`default`, `auto`,
  `bypassPermissions`).
- `term_confirm_dialogs` — Рик сам подтверждает диалоги первого запуска в чатах (доверие к папке вне
  `projects_root`, режим без вопросов или auto).
- `wake_on_mail` — будить Рика ответами чатов сразу; каждое пробуждение — платный ход.
- `notify` — `sound` и `banner` для уведомлений, `long_turn` — звук после хода дольше минуты.
- `voice` — озвучка ответов: `say` (Мак) или `elevenlabs`.
