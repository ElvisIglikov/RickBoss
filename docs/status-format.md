# status.md — форма

Чат проекта ведёт `docs/status.md` (нет `docs/` — `status.md` в корне). Рик читает его построчно и отвечает
хозяину «что у нас», не дёргая чат. Только счёт и время, без пересказа. Обновляй на каждом шаге.

```
# <Проект>
обновлено ЧЧ:ММ

2 воркфлоу
1 готово
1,5 ч потрачено

1️⃣ Workflow ✅ готово
- о чём: одна строка
- шаги 2 из 2
- 10:05 → 11:10 · 1 ч
- кодинг · 2 агента · <модель с версией> <эффорт>

2️⃣ Workflow 💭 идёт
- о чём: одна строка
- шаги 1 из 3
- 11:20 → закончит в 12:00 · идёт 25 мин
- проверка · 1 агент · <модель с версией> <эффорт> 💭

Сейчас: одно предложение.
Ждёт хозяина: одно предложение (только если ждёт).
```

- Слова ровно эти: «N воркфлоу», «N готово», «N ч потрачено», «Workflow», «о чём:», «шаги N из M», «Сейчас:»,
  «Ждёт хозяина:» — свои Рик не поймёт.
- Состояние — значок и слово: ⬜ запланирован · 💭 идёт · ✅ готово · 🛑 упал. Задуманный пиши сразу: «о чём»,
  «шаги 0 из N», роли.
- Под заголовком — пункты `- `, по одной величине. Роли: планирование, критика, кодинг, проверка; у идущей — 💭.
- Время — минуты до часа, дальше часы с одним знаком.
- Только воркфлоу текущего чата: новый чат уносит закрытые блоки, с датой, в `docs/status-archive.md`
  и нумерует с 1️⃣.
