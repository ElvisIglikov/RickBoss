# Разговор голосом (live) — по желанию

Страница `live/` — разговор с Риком голосом в браузере: голосовая модель OpenAI слушает тебя, на простое отвечает
сама, а поручения кладёт в почту Рика (`tools/rick_bus.py`). Ответы Рика (`voice/rick_voice.py say`) она пересказывает
вслух. Без ключа OpenAI live выключен — остальной Рик работает и так.

## Как включить

1. Ключ OpenAI — в `voice/.env` одной строкой (файл в `.gitignore`, в репозиторий не попадает):

   ```
   OPENAI_API_KEY=<твой ключ>
   ```

   Ключ живёт только в локальном сервере: на страницу он не уходит. Для запасной модели (`realtime`) странице
   выдаётся только временный ключ сессии.
2. Чтобы голос будил Рика сразу, а не ждал твоего следующего слова в чате, — в `config.json`:
   `"wake_on_mail": true`. Каждое пробуждение — платный ход модели; ответы терминалов тоже начнут будить Рика
   (пачкой, раз в 20 с, пока кеш тёплый).
3. Запусти Рика (`claude` в папке Рика), потом:

   ```
   live/start.sh            # GPT-Live-1, основной
   live/start.sh realtime   # gpt-realtime-2.1, запасной
   live/start.sh stop       # погасить сервер
   ```

   Страница откроется в Google Chrome на `http://127.0.0.1:8787` (порт — `LIVE_PORT`). Сервер слушает только
   127.0.0.1 и принимает фразы только от страницы, которую сам отдал.
   Порт занят сервером другой копии Рика или чужой программой — `start.sh` её страницу не откроет, а скажет
   задать свой порт: `LIVE_PORT=8788 live/start.sh`.

## ⚠ Что уходит в OpenAI

- **`memory/NOW.md` целиком** и строки сегодняшнего журнала со словами «решение», «готово», «ждёт» — в инструкции
  голосовой сессии, чтобы голос сам отвечал на «что там по делам». Не держи в `NOW.md` того, что не готов отдать
  OpenAI: пароли, телефоны, данные клиентов, суммы.
- Твой голос и его расшифровка, ответы Рика, которые голос пересказывает.
- Минуты платные (у GPT-Live-1 — порядка $0,05 в минуту); после 10 минут тишины страница сама закрывает сессию. <!-- public-ok: цена сервиса -->

## Если не работает

- «Нет ключа» — проверь `voice/.env` и имя переменной `OPENAI_API_KEY`.
- Голос говорит «Рик занят — фраза у него в почте» — Рик в ходе или `wake_on_mail` выключен: фраза дойдёт
  с его следующим ходом. Состояние почты: `python3 tools/rick_bus.py state`.
- Журнал сервера — `live/log/` (в `.gitignore`).
